# HS Security — app downloads

Install files for the HS Security Android app. **No source code lives here** —
this repository exists only so a phone can download an update.

The app checks for a new build itself and shows a banner when one is published;
the link it opens points at a release on this page. That download has to work in
a plain browser with no sign-in, which is why this repository is public while the
app's own code is not.

## Installing

Open the `.apk` on the phone and allow installs from the browser when Android
asks. The `-phones` file covers every Android phone — 64-bit and 32-bit ARM.

Nothing here is useful without a login to the company's system.
